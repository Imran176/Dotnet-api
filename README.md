## 💻 Getting Started

To run the examples locally:

Install the .NET SDK.

Clone this repository:
```
git clone https://github.com/Imran176/Dotnet-api.git
```

Navigate to the project directory:
```
cd Learning-DotNet-WebAPI
```

Restore dependencies:
```
dotnet restore
```

Run the project:
```
dotnet run
```
